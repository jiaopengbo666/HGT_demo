# SARG protein database

SARG3.2.1-S.fasta contains 12,746 protein sequences and is the default ARG database. All reference IDs match data/SARG_names.tsv. File size and SHA-256 are recorded in SARG3.2.1-S.source.json.

Use --arg-db to select another protein FASTA. Indexes are built on first use and cached for later runs; --arg-db-cache sets the cache directory.
