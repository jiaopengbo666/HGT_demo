# SARG annotation map

SARG_names.tsv contains 13,673 reference IDs with gene, subtype and type labels, matched by exact subject_id. Gene labels use the subtype suffix after `__`.

Source: Supplementary_Data_第二轮.xlsx, Supplementary Data 2. Extraction details and checksums are recorded in SARG_names.source.json. Use `--arg-map` to supply another table; ARG protein sequences are supplied separately.
